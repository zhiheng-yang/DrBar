# Code of Conduct

DrBar follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussions about the work. Harassment and personal
attacks are not tolerated in issues, pull requests or any other project space.

To report a problem privately, write to the maintainer at the address on their
[GitHub profile](https://github.com/zhiheng-yang). Reports are handled confidentially.
